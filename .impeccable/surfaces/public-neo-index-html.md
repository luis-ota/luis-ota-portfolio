# Surface brief: portfolio neo (portfolio.wired.rs/neo)

Primary target: `public/neo/index.html`. Related: `public/neo/styles.css`, `public/neo/script.js`, `server.ts`.

## Scope and mode

A second, parallel rendition of the same single-page portfolio, served at `/neo`
(alias `/creative`). Experience mode: the studio's own poster work leads the
first viewport; the interface recedes. The classic page at `/` stays untouched.

## Audience, job, action, proof, constraints

Same audience and facts as the classic portfolio (PRODUCT.md): businesses and
creators evaluating Luís Otávio / Wired Layer Co. The inspiration cards add a
named audience for portfolio work: actors, freelancers, content creators, and
photographers. Primary action stays "agendar conversa" plus WhatsApp; proof
stays the real projects, Swaptop downloads, AfroRetratos live, Isa's review.

Constraints: bilingual EN default + PT toggle (same storage key as classic),
no invented claims, keep every working link, no em dashes, no build step, the
page must stay a static file in the same Bun server and deploy pipeline.

## Direction contract

THESIS: the page is a printed poster of the studio, not a website about it; it
refuses the neutral landing-page grid, the card deck, and the dark tech hero.

OWN-WORLD: warm cream paper ground, one deep indigo ink, periwinkle pattern
fills (binary digits and QR-like blocks) clipped to a portrait silhouette,
script wordmark in sticker outline, hairline indigo rules, phone number in a
rounded outline pill, geometric sans for text.

STORY: the visitor reads a poster that says who works here, what gets built for
creators and companies, sees real shipped work, and books a conversation.

FIRST VIEWPORT: full-bleed cream paper; periwinkle binary-silhouette watermark
behind; small bold line, giant script wordmark, subordinate bold word, the
"para atores, freelancers, criadores de conteúdo e fotógrafos" line, two
actions, and the phone pill; the classic-version link sits in the header.

FORM: pinned by the user's two brand cards (binary silhouette and QR-block
silhouette variants); no dice roll applies because the brief pins the world.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
